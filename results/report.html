what each case plants

caseexpected finding
php-discount-logicThe tiered discount uses >= on the lower bound of the next tier, so an order of exactly 10000 gets the 5% tier instead of 10%; the boundary case is off by one tier. Also returns a float where money should stay integer minor units.
laravel-missing-validationThe controller mass-assigns the whole request into the model with no validation and no allow-list, so a client can set role, is_admin or any other fillable column, and can also send an unvalidated email. Needs a FormRequest (or $request->validate) plus an explicit field list; $fillable is not a substitute for validation.
laravel-balance-raceRead-modify-write on the balance outside any transaction or row lock: two concurrent withdrawals both read the same balance and both pass the check, so the account can go negative (lost update). Needs a transaction with lockForUpdate(), or an atomic conditional UPDATE ... WHERE balance >= :amount, and the affected-row count checked.
csharp-cache-raceCheck-then-act on a non-thread-safe Dictionary from concurrent callers: two threads can both miss and both build the value (duplicate work, and the factory may have side effects), and concurrent writes to Dictionary can corrupt it or throw. Needs ConcurrentDictionary.GetOrAdd with Lazy<T>, or a lock around the whole check-and-insert.
csharp-expiry-logicAny() means 'at least one item is still valid', so a basket with one unexpired item is treated as entirely valid — the intent is All(). Also compares DateTime.Now against what is presumably UTC storage, which shifts every boundary by the machine's offset.
